# MAGXQWORQS Portfolio

A responsive, art-directed graphic design portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

1. Push this project to a GitHub repository.
2. In GitHub, open the repository settings and enable Pages with the source set to "GitHub Actions".
3. Keep the workflow in [.github/workflows/deploy.yml](.github/workflows/deploy.yml) in the repo.
4. Push to the default branch and the action will publish the site.

Your site will be available at:

```text
https://<your-username>.github.io/<your-repo-name>/
```
